Interview Questions ⭐
Q1. Why does MongoDB use $set?

Because MongoDB must distinguish between:

updating specific fields ($set)
replacing the entire document (replaceOne)

Without update operators, MongoDB couldn't know your intent.

Q2. Difference between matchedCount and modifiedCount?

Example:

Document

{
    "city": "Hyderabad"
}

Update

{
    $set: {
        city: "Hyderabad"
    }
}

Result:

matchedCount = 1
modifiedCount = 0

The document matched, but nothing actually changed.

Q3. Can $set create a new field?

✅ Yes.

Interview Questions ⭐
Q1. Difference between updateOne() and replaceOne()?

updateOne() modifies only the specified fields using update operators.

replaceOne() replaces the entire document (except _id) with the new document.

Q2. Can replaceOne() change _id?

No.

MongoDB preserves the original _id, and attempting to replace it with a different value results in an error.

BULK Write


await db.collection("users").bulkWrite([

    {
        insertOne: {
            document: {
                name: "Rahul",
                city: "Bengaluru"
            }
        }
    },

    {
        updateOne: {
            filter: {
                name: "Amit"
            },
            update: {
                $set: {
                    city: "Hyderabad"
                }
            }
        }
    },

    {
        deleteOne: {
            filter: {
                name: "Sneha"
            }
        }
    }

]);

Acknowledgement

| Method         | Important Return Fields                                                        |
| -------------- | ------------------------------------------------------------------------------ |
| `insertOne()`  | `acknowledged`, `insertedId`                                                   |
| `insertMany()` | `acknowledged`, `insertedCount`, `insertedIds`                                 |
| `updateOne()`  | `acknowledged`, `matchedCount`, `modifiedCount`, `upsertedCount`, `upsertedId` |
| `updateMany()` | `acknowledged`, `matchedCount`, `modifiedCount`                                |
| `replaceOne()` | `acknowledged`, `matchedCount`, `modifiedCount`                                |
| `deleteOne()`  | `acknowledged`, `deletedCount`                                                 |
| `deleteMany()` | `acknowledged`, `deletedCount`                                                 |
| `bulkWrite()`  | `acknowledged` plus insert/update/delete counts                                |
