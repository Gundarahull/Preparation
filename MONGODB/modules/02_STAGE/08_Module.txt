| Operator | Meaning                    | Example             |
| -------- | -------------------------- | ------------------- |
| `$eq`    | Equal                      | age = 25            |
| `$ne`    | Not Equal                  | age ≠ 25            |
| `$gt`    | Greater Than               | age > 25            |
| `$gte`   | Greater Than or Equal      | age ≥ 25            |
| `$lt`    | Less Than                  | age < 25            |
| `$lte`   | Less Than or Equal         | age ≤ 25            |
| `$in`    | Match any value in a list  | status IN (...)     |
| `$nin`   | Match values not in a list | status NOT IN (...) |

between - {
   salary:{
      $gte:50000,

   }

1. Can you mix inclusion and exclusion?

❌ No.

Example:

{
    name: 1,
    phone: 0
}

is invalid.

The only exception is:

{
    name: 1,
    _id: 0
}
Q2. Why use Projection?

Reduce network bandwidth
Reduce memory usage
Improve response time
Enable covered queries with indexes
