
=============================================================================================================
                                                   UPDATE OPERATORS
==================================================================================================



| Operator       | Purpose                                   |  Creates Field?  |   Removes Field?   | Used With                 |
| -------------- | ----------------------------------------- | :--------------: | :----------------: | ------------------------- |
| `$set`         | Add or update a field                     |       ✅ Yes      |        ❌ No        | `updateOne`, `updateMany` |
| `$unset`       | Remove a field                            |       ❌ No       |        ✅ Yes       | `updateOne`, `updateMany` |
| `$rename`      | Rename a field                            |    ✅ New name    | ✅ Old name removed | `updateOne`, `updateMany` |
| `$setOnInsert` | Set fields only when inserting via upsert | ✅ On insert only |        ❌ No        | `upsert: true`            |




=============================================================================================================
                                                   ARRAY OPERATORS
==================================================================================================



| Business Requirement         | Operator                                                |
| ---------------------------- | ------------------------------------------------------- |
| User adds a skill            | `$push`                                                 |
| User adds a unique role      | `$addToSet`                                             |
| Remove oldest notification   | `$pop` (or more commonly `$slice` in advanced patterns) |
| Remove an item from wishlist | `$pull`                                                 |
| Delete a specific address    | `$pull`                                                 |
| Remove failed exam marks     | `$pull` with condition                                  |



| Requirement                   | Modifier           |
| ----------------------------- | ------------------ |
| Add many skills               | `$each`            |
| Add notification at beginning | `$position`        |
| Keep last 20 searches         | `$slice`           |
| Maintain leaderboard          | `$sort` + `$slice` |
| Import multiple tags          | `$each`            |


🏆 Update Operators Practice Arena
🟢 Level 1 (Warm-up)
Exercise 1 — $set

Update Rahul's city to Hyderabad.

db.users.updateOne({
    firstName:'Rahul'
},
{
    $set:{
        city:'Hyderabad'
    }
})

Collection: users

Exercise 2 — $unset

Remove the phone field from Rahul's document.
db.users,updateMany({},{$unset:{
    phone:1
}})

Exercise 3 — $rename

Rename the field

phone

to

mobileNumber

db.users.updateMany({},{$rename:{phone:mobileNumber}})
Exercise 4 — $inc

Increase Rahul's rewardPoints by 250.


db.users.updateOne({
    firstName:'Rahul'
},{
    $inc:{
        rewardPoints:250
    }
})

Exercise 5 — $mul

Double Rahul's salary.
db.users.updateOne({
    firstName:'Rahul'
},{
    $mul:{
        salary:2
    }
})

MongoDB
